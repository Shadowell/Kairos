# 数据窗口与打包可靠性修复

## User Scenarios & Testing
### US1 (P1): 精确选择采集与训练窗口
用户输入日期或 ISO 时间范围，得到完整结束日或精确时间边界；在不同本机时区运行结果一致。
验收：分钟级单日包含 1440 行；带时分秒/时区范围可解析；显式零点不扩展到次日。
### US2 (P1): 可靠的数据打包
缺失或部分缺失 amount 使用 close*volume；输入/范围无效、所有数据不可用时非零退出且不覆盖已有输出。
验收：输出主通道与 32 维外生通道对齐；错误命令保留已有文件。

## Requirements
- FR-001 保持 YYYY-MM-DD:YYYY-MM-DD，支持 ISO 时间端点（含时区偏移）；非法、倒序范围清晰失败。
- FR-002 日期结束端覆盖整日，显式时间端保持精确的包含边界；采集无时区输入按 UTC。
- FR-003 缺失/NaN amount 回填，同时保留有效的已有 amount。
- FR-004 CLI 在处理前验证范围，发现范围重叠拒绝；没有输入或缺少任一必需 split 时禁止写输出。
- FR-005 保持输出格式、外生因子顺序和维度不变。

## Success Criteria
- SC-001 新增回归用例先复现再通过，原有测试通过。
- SC-002 真实离线 parquet 经 CLI 打包成功；错误调用非零退出且已有输出不变。

## Assumptions and Scope
已有示例的日期范围是结束日包含语义。显式时间的结束点继续包含。
本轮聚焦数据入口确定性缺陷，不改模型、训练参数、交错采样策略、服务部署或历史数据。
