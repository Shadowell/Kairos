# 统一数据、训练、评测与推理契约

## User Scenarios & Testing
### US1 (P1) 可信时间序列
交错切分按真实日历天且各币种共享时间块；窗口不得跨缺口、重复时间或 split 边界。训练按索引确定性取样，分布式分片实际有效。
### US2 (P1) 一致的学习目标与模型选择
在最后一个历史 bar t 预测 log(close[t+h]/close[t])，h=1..H。训练与验证都使用相同联合目标；mask 全 1 等价无 mask。运行目录唯一，checkpoint 绑定 tokenizer、schema、配置与数据摘要。
### US3 (P1) 可解释的评测与服务
回测和 HTTP 使用同一个推理器、锚点、归一化和 schema。baseline 使用原版 Kronos 的真实预测；横截面 IC 先按同一时刻计算，再按日/小时汇总。服务输出收益分位数及价格中位数，不将路径占比称作概率。

## Requirements
- FR-001 UTC 日历切分；窗口仅使用连续同频数据，跨币种块分配一致。
- FR-002 返回索引对应的确定性样本，训练 epoch 采样可复现，验证固定；外生列、顺序、时间索引与数值必须严格校验，不再静默补零/截断。
- FR-003 标签来自未归一化、未截断的正价格；锚点为 lookback-1，跨度按 bar 数；只监督可见历史锚点。
- FR-004 mask 损失按全部有效元素归一化；选模联合验证目标，DDP 早停决策一致；空训练/验证明确失败。
- FR-005 独立 run 目录禁止覆盖；模型包保存 manifest、配置、数据 SHA256、源码 SHA、tokenizer 文件及校验值。旧包缺少新契约必须明确拒绝，不冒充 log-return 模型。
- FR-006 回测和服务共享推理组件；严格核验频率、特征、历史长度、预测期限；服务返回 horizon 分位数，取消未经校准的概率宣称。
- FR-007 baseline 不使用随机收益头，固定并记录种子；支持多种子重复。按时刻横截面、按币种时序及 pooled 诊断分别报告，少于 3 币种的截面不产生 IC。
- FR-008 原始数据和旧实验文件不修改；不部署、无付费训练；更新现有文档的失效契约和历史结果适用边界。

## Success Criteria
离线回归覆盖六组缺陷；真实小型模型执行训练→保存→加载→回测→HTTP；pytest -x 通过。尝试真实 Kronos-small 权重加载和本地 CPU smoke，外部下载不可达时如实报告限制。

## Compatibility and Clarifications
保持 32 个外生因子及 pickle 主通道格式。新模型包版本为 2，target=log_return；旧包不自动转换。历史指标保留且标为旧评测口径。API 新增明确分位数输出；原版 Kronos 保留在 baseline 回测入口；HTTP 仅服务 v2 模型包，旧路径占比不作为概率。
